# 《深夜电台 · Midnight Signal》序章配音文稿

适用范围：序章《空频》
交付方式：每条台词一个独立音频文件，文件名必须与下表的 **ID** 完全一致，扩展名 `.mp3`，放到 `assets/voice/` 目录下。

放入文件后，把 `game.js` 里 `Voice.enabled` 改为 `true`，游戏就会在每句台词出现时自动播放对应音频。

---

## 一、角色与音色建议

| 角色 | 建议 | 说明 |
| --- | --- | --- |
| 老周 | 男声，50–60 岁 | 偏低、语速慢、带海风和疲惫感；不要播音腔，像在雾里对着话筒说话 |
| 旁白 | 女声，25–35 岁 | 中性、冷静、贴近耳边，音量比老周略低 |
| 处理 | 老周全部做「电台化」 | 带通 300–3000Hz、轻微失真、底噪；旁白保持干净 |

> 老周的所有台词都发生在无线电里，可以统一加一点电流底噪和轻微压缩；旁白是玩家视角，不加处理。

## 三、交付清单

- 共 25 条：`intro_01`–`intro_02`（2）、`tune_01`–`tune_03`（3）、`call_01`–`call_06`（6）、`beacon_01`–`beacon_08`（8）、`music_01`–`music_03`（3）、`news_01`–`news_03`（3）
- 格式：`.mp3`，单声道即可，采样率 44.1kHz，单条建议 ≤ 8 秒
- 命名：`intro_01.mp3`、`call_02.mp3` …（严格小写，下划线）
- 目录：`assets/voice/`
- 每条开头留 100ms 静音、结尾留 200ms，避免播放时被切字
- 不需要做背景雨声，雨声由游戏实时合成
